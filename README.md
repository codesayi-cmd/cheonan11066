# 프레드릭 | 인터랙티브 그림책 클래스

첨부된 《프레드릭》 6장 PowerPoint를 기반으로 한 정적 웹 프레젠테이션입니다.

## 실행 방법
- `index.html`을 브라우저에서 열면 됩니다. 서버와 데이터베이스가 필요하지 않습니다.
- 화면 상단 목차, 오른쪽 아래 이전/다음 버튼, 키보드 방향키, Page Up/Down, Home/End, 스크롤 또는 모바일 스와이프로 페이지를 이동합니다.
- 4장에서는 카드를 클릭해 준비의 의미를 살펴보고, 6장에서는 보물을 선택할 수 있습니다.

## GitHub Pages 게시 방법
1. 압축파일을 풀고 `index.html`과 `assets/` 폴더를 같은 저장소 최상위 경로에 올립니다.
2. GitHub 저장소의 **Settings → Pages → Build and deployment → Deploy from a branch**를 선택합니다.
3. `main` 브랜치의 `/ (root)`를 선택하여 저장합니다.
4. 게시 주소 `https://<계정>.github.io/<저장소>/`에서 확인할 수 있습니다.

이미지 참조는 모두 `./assets/...` 상대경로라 프로젝트 페이지에서도 작동합니다. Google Fonts 연결이 차단되면 시스템 폰트로 대체됩니다. 원본 PPT에서 추출한 이미지는 `assets/`에 포함돼 있습니다.

## 구성
- `index.html` — HTML, CSS, JavaScript를 모두 포함한 독립 실행 페이지
- `assets/` — PPT에서 추출한 6개 이미지

## 출처 및 사용 시 유의사항
- 원본 프레젠테이션의 내용과 이미지가 그대로 반영되었습니다.
- 원본에 기재된 자료 출처: [Penguin Random House](https://www.penguinrandomhouse.com/books/101916/frederick-by-leo-lionni/), [Random House Children's Books](https://www.rhcbooks.com/books/101916/frederick).
- 삽화는 원본 PPT에 들어 있던 이미지입니다. **웹에 공개 게시할 경우 그림책 삽화에 대한 사용 허가 및 저작권 조건을 별도 확인**하세요. 웹으로 변환했다고 해서 공개 이용 권한이 자동으로 부여되지는 않습니다.
